## Intent

Réplica del motion design del vídeo de referencia "Apple for Launch Videos"
(estilo UI limpio tipo Apple: fondo blanco roto, Inter, cursores multijugador
tipo Figma, escritura con cursor, cámara que sigue el texto, transiciones por
desenfoque), adaptada a la campaña "Trato Usuario 2026" de CRS — SAG.

## Assets

- assets/fonts/Inter-*.otf — tipografía Inter (copiada del sistema).
- assets/vendor/gsap.min.js — GSAP 3.14.2 local (el CDN está bloqueado en este entorno).

## Customizations

Guion por escenas, tal como lo pidió el usuario:

- 0–1,7 s — "Presentamos" escrito letra a letra, pequeño y centrado.
- 1,7–2,8 s — cursor "CRS"; un punto crece a círculo y entra una "T".
- 2,8–5 s — "Trato Usuario 2026" gigante, cámara sigue el cursor.
- 5–6,3 s — zoom out; "2026" en degradado azul→violeta→rosa; etiquetas
  Escuchar (naranja), Respetar (violeta), Informar (azul), Acoger (verde), Cuidar (rojo).
- 6,3–9,9 s — caja de prompt: "¿Cómo lograr un buen trato al usuario?"; CRS pulsa enviar.
- 10–13,5 s — lista: Proceso de Atención… / Infraestructura… / Resultado y tiempo…
  con barras de progreso; pie "Todo comienza cuando llega el paciente".
- 13,5–15,5 s — "Todo comienza / cuando llega el paciente" + píldora "● Paso a paso".
- 15,5–20,5 s — ventana "CRS SAG — live preview", wireframe "TRATO HUMANO",
  "Saludar y presentarse", 3 paletas, cambio a modo oscuro.
- 20,5–21,5 s — "✓ Cada interacción cuenta" con etiquetas que se dispersan.
- 21,6 s–final — cierre "Logremos el tramo I" + cursor CRS + "CRS — SAG".
